# GOD bell-chain benchmark comparison

Status: concluded; mechanic rejected for production.

The high-pure-increase benchmark showed that a Gaisen-style ordinary GG yellow-7/bell streak reward would consume too much EV if carried over directly.

That result is now a design constraint:
- no ordinary GG bell-streak V-stock
- no EV budget reserved for that mechanic
- no gameplay implementation for it

The comparison code remains only to preserve the reasoning that led to this decision.
