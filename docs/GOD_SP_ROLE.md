# Piri GOD — SP role locked

SP役は採用する。

Production baseline:
- SP役: 1/65536
- 通常時/GG中の基準: 50%でGGストック1個
- そのストックに80%ループを付与

現在の1GG=+350枚純増という経済モデルでは、

- 80%ループ1個の期待追加ストック = 4個
- 「1個 + 80%ループ」を50%で獲得するため、SP役1回あたりの期待総ストック = 2.5個
- EV換算 = 2.5 * 350 = +875枚/SP
- 1/65536なので、対象ゲーム1Gあたり約 +0.01335枚のEV寄与

これは通常時/GG中の基準値として扱う。
SGG中など、SP役の別コンテキスト恩恵は、その状態の仕様を組む段階で個別に定義する。
