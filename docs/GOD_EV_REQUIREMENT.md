# Piri GOD — positive-EV requirement by setting

This step turns the locked target curve and published normal coin base into a
budget for the positive-return systems.

Reference normal base:
- 50 medals / 30.8 games
- net normal-play loss = about 1.6233766 medals per normal game

Locked target payout:
- S1 97.2%
- S2 99.1%
- S3 102.1%
- S4 106.9%
- S5 111.7%
- S6 114.6%

For the normal-spin EV budget anchor:

required positive EV per base game
= target net per game - normal-base net per game

Using the locked target curve gives approximately:

| setting | target net/game | required positive EV/game |
|---:|---:|---:|
| 1 | -0.084 | 1.5394 |
| 2 | -0.027 | 1.5964 |
| 3 | +0.063 | 1.6864 |
| 4 | +0.207 | 1.8304 |
| 5 | +0.351 | 1.9744 |
| 6 | +0.438 | 2.0614 |

If GOD is provisionally valued at 3000 net medals, independent 1/8192 contributes
about +0.36621 medals per eligible game. The remaining budget must then be supplied
by normal GG initial hits, loop stock, SGG/red-7, Z routes, and other retained
Kiseki-style systems.

Important: this table is an EV fitting anchor, not final payout verification.
AT creates additional games and therefore changes both total wager and total payout.
The completed machine must still be checked with full state/cycle simulation.
