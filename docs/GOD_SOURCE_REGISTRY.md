## Source-handling rules

- Stop-form illustrations are representative examples unless a source explicitly states a complete control table.
- Current public material does not justify calling a Piri press-index control table “exact real-machine control.”
- If two Tier A/B sources disagree, mark the item disputed and do not implement it as authentic until reconciled.
- Older GOD-family machines may be used only as historical context, never as a substitute for Kiseki data.
