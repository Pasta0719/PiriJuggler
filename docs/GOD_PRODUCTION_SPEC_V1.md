# Piri GOD v1 production specification

Status: LOCKED gameplay baseline. Economy calibration may change normal-side hit/mode-transition parameters only; it must not weaken AT/loop/premium rules listed here.

## Fixed Piri rules

- GOD: independent 1/8192 in every setting/state.
- GOD reward: four guaranteed GG sets total plus one D (80%) loop stock.
- RED7: 1/6900.
- SP: 1/65536.
- GG: 50 games, approximately +7.0 medals/game pure increase.
- G-ZONE: max 5 games.
- Loop classes: A=1%, B=25%, C=50%, D=80%.
- Normal ceiling: 1480G.
- Reset ceiling: 510G 15.2%, 1000G 20.3%, 1480G 64.5%.
- SP during normal/GG: 50% for one GG stock + D loop.
- Z-ZONE: 5G base, yellow-7 appearance about 1/1.4; yellow-7 pauses countdown and five consecutive yellow-7s awards GG and enters Z-GAME.
- Z-ZONE zero-yellow failure: 50% for D loop.
- Ordinary GG bell-streak V stock: disabled.
- Target payout curve: 97.2 / 99.1 / 102.1 / 106.9 / 111.7 / 114.6%.

## Economy fitting rule

Payout fitting is allowed on the normal-game side only (unpublished/implementation-owned mode-transition and normal GG-hit parameters). Do not fit payout by reducing GOD, loop, SGG, Z-ZONE/Z-GAME, G-ZONE or GG-after-hit performance.

Published Kiseki mechanics remain the behavioral reference where values are public. Values that are still unpublished are Piri-specific implementation values and must be labelled as such rather than presented as authentic Kiseki data.
