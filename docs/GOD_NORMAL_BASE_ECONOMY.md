# Piri GOD — normal-play coin base

A published Kamigami no Kiseki reference gives:

- setting 1 normal base: about 30.8 games per 50 medals

At a 3-medal wager this converts to:

- net normal-play consumption: 50 / 30.8 = about 1.6234 medals/game
- gross ordinary return inside normal play: 3 - 1.6234 = about 1.3766 medals/game
- normal-play gross return ratio: about 45.89%

This **45.89% is not the machine payout**. It only describes the ordinary normal-play coin base before AT/premium value is added.

The value is useful because it gives the EV fitter a real base-game loss anchor instead of an invented one.

Only the published setting-1 base is locked here. Other settings are not assumed to have a different base unless a source or deliberate Piri design decision says so.
