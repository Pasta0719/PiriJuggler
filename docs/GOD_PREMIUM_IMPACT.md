# Piri GOD — premium-rate impact

Verified Kiseki baseline:

- GOD probability: 1/16384
- GOD benefit: dedicated 50G GOD stage + three GG stocks, i.e. four GG-equivalent 50G blocks in total
- plus a strong loop stock
- published expectation: 3000+ medals
- RED 7: 1/6900, enters SGG + one GG set + loop stock

Piri deliberately changes GOD to an independent 1/8192 while retaining the Kiseki-style reward package.

## Immediate economic consequence

At the current +7.0 net medals/game and 50G/GG baseline:

- one plain GG-equivalent block = +350 net medals
- four guaranteed blocks = +1400 net medals before valuing the strong loop stock

Changing only the GOD rate from 1/16384 to 1/8192 therefore adds at least:

- +1400 / 16384 = +0.08544921875 net medals/game
- at a 3-medal wager, at least +2.8483 payout percentage points

This is a strict lower bound because it gives the additional strong loop stock zero value.

Therefore the original Kiseki payout curve cannot be preserved by copying every probability unchanged. Some non-GOD economic contribution must be reduced if Piri keeps the same target payout percentages.

The production engine remains blocked until the full premium/loop value is modeled.
