# HYPER_DOG — 設計正本（Phase計画ドラフト）

**状態：初期実装仕様を固定。Phase実装・実Minecraft試験は別途。未決定事項は [IMPLEMENTATION_DECISIONS_V1.md](IMPLEMENTATION_DECISIONS_V1.md) で解消済み。**

## 1. ユーザー確定：ゲームシステム
- 3BETのオリジナルAT直撃機。BIG/REGの別ボーナスに置き換えない。通常の単独AT当選と役重複AT当選を併用。
- 通常時6モード `LOW_A`/`LOW_B`/`NORMAL_A`/`NORMAL_B`/`HIGH`/`SUPER_HIGH`。モード差は原則**単独AT当選確率だけ**で、役重複AT当選率は固定。役・連続成立で昇格、ハズレ時のみ自然転落。AT中は通常モード抽選を進めず、当選時保存モードに基づき完全終了後に再抽選。
- 内部役 `MISS`, `REPLAY`, `GRAPE`, `WEAK_CHERRY`, `WATERMELON`, `CHANCE`, `STRONG_CHERRY`, `STRONG_CHANCE`, `BAR`。ベル等の不要な役を追加しない。
- 有料通常/ATゲームは3BET、REPLAYの次の有料ゲームだけ0BET。特殊区間は **0BET・0払出**で、前後のリプレイ残権利が漏れない。通常GRAPE3枚、AT GRAPE30枚。チェリー1枚、スイカ/チャンス系5枚、BAR15枚。
- REPLAY/GRAPEは別々に連続回数を数える。3連でモードアップ抽選、4連でモードアップ確定かつAT重複20%、5連でAT確定。弱チェリー/スイカ2連には専用抽選。モードアップは元仕様の強弱を守る。
- 下位ATの初期枚数：無料**1G**、150枚保証＋役別加算・独立加算。下位AT中のレア役で差枚上乗せと上位CZ権利。CZ権利1個目は挑戦、2個目は突破保証、3個目以降は上位初期のレア役保証枠に換算（5Gを延長しない）。
- 上位ATの初期枚数：無料**5G**、各G+100枚保証で計500枚以上。通常上乗せは下位の**厳密な5倍**、上位中は追加CZ権利を発生させない。上位有料ATのハズレは1/32でレア役へ書換。強チェリー・強チャンス目の特別な薄い抽選で1回+2,000枚。AT全体の合計差枚数は無制限。
- 上位CZ：5G中の**通常抽選合計50%**、早期成功で終了。下位差枚消化後にCZ権利があれば挑戦、失敗した場合は再び下位初期1Gへ。上位差枚消化後は必ず上位CZ、失敗ならAT完全終了。
- BARは超低確率。通常時/下位AT中なら次ゲーム上位ATへ直接移行、下位の残り差枚は持越し。上位AT中BARは次回CZ突破を保証し、次回上位初期のレア役保証も与える。複数権利を喪失させない。
- AT完全終了後、32有料Gの引き戻し区間。通常の単独・役重複抽選を継続し、独立引き戻し抽選も行う。引き戻したATは下位初期1Gから（BARは上位直撃）。
- 目標機械割：設定1→6＝**97.0 / 99.3 / 102.5 / 104.8 / 107.4 / 116.0%**。

## 2. ユーザー確定：筐体・リール・告知
- 操作部（LEVER、既存BET、左右中の停止ボタン）、CREDIT/BET/PAY/MEDALS は**現行 `SlotLayout.java` に従い既存配置を維持**。MAX BETを両端に移動しない。既存のデータランプや資産導線も残す。
- 3リール中央。左右上の当選告知ランプはハナハナ風の位置に各1灯、**告知のタイミング/条件は既存PiriJugglerと同様**。文字は操作ボタン・CREDITなど必要な数字表示に限定し、筐体に STATUS / LOWER / UPPER / CZ / ADD の文字を飾らない。
- リール左側＝状態ランプと上乗せ小型液晶、右側＝期待度演出用の縦3灯。左側3状態灯の案は【試作OK】（下位/上位/CZ）。
- **ユーザーは図柄画像だけを用意する。配列（各リール1周の図柄順序）・停止制御は開発側が設計する。** 弱チェリー＝**左・中リールのチェリー2連**、強チェリー＝**3リールのチェリー3連**。**弱チェリーは上/下段の左中横2連、強チェリーは左上/下段を含む5ライン3連。左チェリー中段はBAR成立時だけ許可**。通常CHANCE＝**赤7/BAR/赤7 が中段**、STRONG_CHANCE＝**赤7/BAR/虹7 が中段**。**通常停止は最大4コマ滑り、レア役とBAR確定役は必ず引き込む。上位CZの虹7とAT当選時の赤7揃いも必ず引き込む（4コマを超える滑りを許容）**。BARは5ライン全てで揃い可能。赤7/BAR/虹7各1個7コマ間隔で、未成立時の特殊図柄3連は混合も禁止。**AT当選時の中段赤7×3**を含む現行配列は [REEL_DESIGN_V2.md](REEL_DESIGN_V2.md) に記録。
- 上位CZはレバーON直後に短い停止入力ロック、その後左右リールが**中段虹7で自動停止**、中央停止ボタンだけ入力可能。当選なら狙いタイミングにかかわらず虹7揃い、非当選なら中央が外れる。CZ当否はサーバー抽選が正本で押下時に変えない。

## 3. ユーザー確定：上乗せ期待度ランプとフラッシュ
- 色序列 **白＜青＜緑＜黄＜紫＜赤＜虹**。赤は通常演出の実質最上位、虹は別格のプレミア。
- **赤ランプ/赤フラッシュは+500枚以上確定**。**虹ランプ/虹フラッシュは+2,000枚確定、他の上乗せには一切使わない**。+2,000枚でも虹の表示は必須でなく、赤なども可。
- レバーONで右1灯。第1停止では2灯化または色変化、第2停止では3灯化または色変化。色変化・点灯数増加が起きない回も許可。灯数と色は独立した期待度軸で、1灯赤と3灯黄の共存が重要。細かな抽選割合は対象Phaseで検証。
- 第三停止で上乗せ結果と左液晶の数字を表示。半透明の色フラッシュがリール全体に高速で重なり、右側最終色と基本連動。試作合意：**同色80%・上位色への昇格20%**（保証違反の昇格は禁止、適格な上位色がない場合は同色100%）。連動フラッシュは第三停止の実際の上乗せ結果を超える保証色を出してはならない。
- 白/青/緑/黄/紫の保証候補は+10/+20/+30/+50/+100枚【試作OK】。色別の詳細分布・ランプ数・点灯タイミング・フラッシュ時間は **[IMPLEMENTATION_DECISIONS_V1.md](IMPLEMENTATION_DECISIONS_V1.md) の決定値**。

## 4. ユーザー試作承認：初期TOTAL、液晶、状態、音
- 下位初期**1Gの第三停止直後は単なる追加枚数表示でなく、決定した初期枚数全体を「TOTAL」の形で提示**する。
- 上位初期**1〜5G**は各ゲームの上乗せを表示。上位AT有料遊技は**次の第6Gから開始**し、**第6G第三停止で5G分の初期獲得合計を「TOTAL」として表示**。第6Gを無料追加抽選・6G目の初期加算にしない。第6Gの成立役による通常AT上乗せとTOTAL演出の重複時は、**第三停止→初期5GのTOTAL 1,400ms→第6G+N 1,200ms→残枚数**の順に表示。
- 左小型液晶：平常時はAT残り枚数、上乗せ時は大きな `+N`、その後元の残り枚数へ。初期枚数時は `TOTAL N` に切替。筐体内の余分な文字は置かないが**TOTALは一時的な数字演出**として許可された前提。
- 左側3状態灯：下位/上位/CZで状態区別。32G引き戻しもランプのダブルパルスで表現。**位置・色・点滅周期・ストックの優先度は実装判断確定表で固定**。
- 操作音等は既存の登録済み`bet/lever/stop/notice/notice_strong/payout/tenpai/bonus_start/bonus_end`を流用。新規サウンドファイル不要。筐体装飾は文字なし、リール/ランプ/小型液晶が主役。
