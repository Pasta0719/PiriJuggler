## 2. 今回決めた役の停止形をどう実現するか

**「左中で2連」は左・中リールにチェリーを横並びで出す**形と解釈。強チェリーは左・中・右のチェリー3個横並び。どちらも**中段に表示**する構成で設計している。縦にチェリーを2個/3個連ねる設計ではない。

| 役 | 停止中段index（左・中・右） | 出目 |
| --- | --- | --- |
| ハズレ | `(0, 0, 1)` | 有効役が揃わない |
| リプレイ | `(0, 0, 9)` | リプレイ3個揃い（下段） |
| ブドウ | `(0, 0, 8)` | ブドウ3個揃い（中段） |
| スイカ | `(4, 2, 7)` | スイカ3個揃い（斜め） |
| **弱チェリー** | **`(2, 6, 0)`** | **中段 チェリー・チェリー・ブドウ**（左・中の2連） |
| **強チェリー** | **`(2, 6, 9)`** | **中段 チェリー・チェリー・チェリー**（3連） |
| **チャンス目** | **`(19, 3, 3)`** | **中段 赤7・BAR・赤7** |
| **強チャンス目** | **`(19, 3, 15)`** | **中段 赤7・BAR・虹7** |
| **BAR** | **`(7, 3, 2)`** | **中段 BAR・BAR・BAR** |
| **上位CZ成功** | **`(14, 7, 7)`** | **中段 虹7・虹7・虹7** |
| **上位CZ失敗** | **`(14, 0, 7)`** | **中段 虹7・ブドウ・虹7** |

上記は**各役を実現できる停止例の一つ**。停止位置は押下タイミングと押し順により、他の合法候補にも変化し得る。リールのコマ数や有効ラインは本案の設計値であり、旧機種へ適用するものではない。

### 役判定の初期設計
- ブドウ・リプレイ・スイカ：上段/中段/下段・右下がり/右上がりの**5ラインのいずれか**に同種3個揃い（基本ライン数は試作案）。
- 弱チェリー：**中段の左＋中チェリー2個、右はチェリー以外**。同じ停止結果が他の入賞役と重ならないこと。
- 強チェリー：**中段チェリー3個**。上下段や斜めの偶然のチェリー3個は強チェリー入賞として扱わない。
- チャンス目・強チャンス目：指定の**中段のみ**。
- BAR、CZ虹7：指定の**中段のみ**。他ラインにBAR/虹7が揃っても偽入賞とならないよう、通常役の合法候補から除外。
- 上位CZ：レバーON後の左右自動停止／中央のみ手動、当選したら必ず中段虹7、非当選なら中段不揃い。CZ自体は0BET・0払出。

## 3. 停止制御の設計

1. PaperでレバーON時に役（またはCZ成功/失敗）を確定。停止ボタンで抽選結果を変えない。
2. 21³＝**9,261通り**の最終停止組合せを走査し、成立役と矛盾しない候補を事前に選別。2つ以上の役が同時成立するような候補も排除。
3. プレイヤーの停止操作に対し、**すでに停止したリールの位置を維持**しながら、残りのリールを必ず合法な最終出目へ導ける候補だけを残す。停止順は左中右に固定しない。
4. 押下インデックス `p` から停止位置 `s` への滑りコマ数は `(p - s + 21) % 21`。短い滑りを優先し、同値なら安定したタイブレークで結果を選ぶ。
5. **4コマ以内を優先するが、すべての役・押下位置での4コマ引込みは保証しない。** この配列案の全役保証には、役によって5〜20コマ先までの追加回転が必要。これは演出・操作感に関わるのでPhase01でまとめて確認し、無承認で「4コマ固定」「瞬間ワープ」「取りこぼしあり」に決めない。
6. レバー抽選・停止履歴・既停止の位置はPaper側で保持してFabricへ同期。途中切断・再接続・通信遅延があっても役と差枚は変わらない。
