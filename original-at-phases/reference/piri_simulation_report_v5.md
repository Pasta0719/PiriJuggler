# PiriJuggler 新機種 — 全体シミュレーション・機械割調整結果

**計測結果：初回v1を全設定で実測した後、調整可能とされた「単独AT当選倍率」のみ変更してv5を作成。独立乱数による再検証も実施。**

## 検証条件

- 入力仕様：`pirijuggler_new_machine_full_trial_v1.json`、調整後：`pirijuggler_new_machine_calibrated_v5.json`。
- 各設定について初期v1：**900万有料G**、調整後v5：**3,600万有料G＋未使用乱数3,600万有料G**。最終v5の総計は**4億3,200万有料G**。
- 上記有料ゲーム以外に、下位初期1G・上位初期5G・上位CZ最大5Gの**0BET・0払い出し**専用ゲームを実行。
- 機械割＝全有料ゲームの**実際の払出総枚数÷実際の投入総枚数×100**。リプレイ後の0BET、AT中の3BET/30枚ブドウを反映。
- 全6モードの移行・転落、役重複・単独当選、役連、差枚数管理、AT上乗せ、CZ失敗時の分岐、BAR、32G引き戻しを処理。
- **これは仕様モデルのMonte Carlo検証。Minecraft実装のリール制御・Paper/Fabric上の動作受入ではない。**

## 平均初期枚数と上乗せの解釈

- 下位AT：初期150枚＋成立役＋独立抽選。実測平均は**約154.5枚**。
- 上位AT：毎ゲーム+100枚を5G、レア役に応じた5倍上乗せを合算。実測平均は**約516〜518枚**（BAR専用+1000や下位残り枚数持ち越しは別）。
- 2,000枚の薄い振り分けは、上位AT中の強チェリー2%、強チャンス目5%。当該ゲームの上乗せ上限は2,000枚だが**ATの累計獲得差枚には上限を置いていない**。
- 上位通常Gのハズレ1/32でレア役への書き換えを実施。初期枚数決定中の余剰CZ権利によるレア役保証とも区別して処理。

## 仕様照合と限界

1. モード昇格先振り分けとAT終了後の再抽選テーブルは各行100%を確認。役の全確率和は各遊技状態で100%。
2. 通常CZ通算50%と32G追加引き戻し抽選通算20%を計算で照合。ここでいう32Gの20%は通常の役重複や単独当選が起こらない場合の追加抽選のみ。実際の32G引き戻し合計はもっと高くなり得る。
3. 下位CZ失敗→下位初期1Gへ復帰、上位CZ失敗→AT完全終了を別経路として実装。BARの上位CZ突破保証も反映。
4. 各ゲームの確率抽選モデルの整合性を調べたが、停止形・虹7自動停止・演出・実Minecraft上の制御は今回の検証範囲外。
5. 1/65,536のBARや上位の長い連鎖は長い尾を作るため、実測機械割は試行数を増やせばなお上下する。目標との乖離を**絶対0.00ポイント**まで保証するものではない。
6. 今回の数値は、実機の法規制・市場上限を満たすかを保証するものではなく、Minecraft用オリジナルスロットの仮設計を検証したもの。

## ファイルと再実行方法

- `pirijuggler_new_machine_calibrated_v5.json` — 最終候補の全抽選パラメータ（元v1との差は設定倍率だけ）。
- `piri_simulate_full_v1.py` — NumPy＋Numbaによるシミュレーター。
- `piri_full_sim_result_v1.json` — 初期v1 5,400万G試行の全出力。
- `piri_full_sim_result_v5.json` — 調整に使用したv5の2億1,600万G試行。
- `piri_full_sim_holdout_v5.json` — 新しい乱数による独立再検証2億1,600万G。
- `piri_simulation_summary_v5.json` — 合算値を収めた小さな集計ファイル。

```bash
python piri_simulate_full_v1.py --input pirijuggler_new_machine_calibrated_v5.json --paid-per-replicate 12000000 --replicates 3 --seed 4126701 --output reproduced.json
```

## 判定

**固定ゲーム性を変更せず、調整対象の単独AT当選倍率だけで目標機械割付近に到達した。** 最終v5の合算実測は設定1〜6で96.97 / 99.17 / 102.55 / 104.79 / 107.29 / 115.78%。実装へ移植するなら数値の正本はv5 JSONとし、Paper側の実抽選がこのモデルと一致するかを別途E2E検証する必要がある。
