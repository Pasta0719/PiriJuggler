# JUGGLER_GOD image assets

このフォルダは JUGGLER_GOD 専用の差し替え素材です。
初期状態では通常の JUGGLER で使っている画像をそのままコピーしてあります。
ここだけ差し替えると通常 JUGGLER には影響しません。

## リール図柄
`symbols/bar.png` — BAR
`symbols/bell.png` — ベル
`symbols/cherry.png` — チェリー
`symbols/grape.png` — ぶどう
`symbols/piero.png` — ピエロ
`symbols/replay.png` — リプレイ
`symbols/seven.png` — 7図柄

## ランプ
`lamp/piri_chance_off.png` — PIRI CHANCE 消灯
`lamp/piri_chance_on.png` — PIRI CHANCE 点灯

画像のファイル名・配置は変えず、中身だけ置き換えてください。
JUGGLER_GOD の画面表示とワールド上の筐体表示は、この専用パスを優先して読み込みます。

通常 JUGGLER の元画像:
`assets/piri/textures/symbols/`
`assets/piri/textures/lamp/`
