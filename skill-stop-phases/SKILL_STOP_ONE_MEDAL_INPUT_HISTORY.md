# 1枚役 — 入力履歴を含む制御候補の検査
Status: DRAFT_CONTROLLER_RESEARCH — SPEC ONLY
Updated: 2026-10-03

## 範囲
採用6種類×通常/Fの2条件×6押し順×21入力の3乗=666,792履歴を列挙した。
研究用の候補選択を作り、禁止形、滑り上限、BIGビタ経路の保護が同時に成立するか確認。ゲーム実装は変更しない。
配列・役判定・左チェリー簡略条件はSKILL_STOP_ONE_MEDAL_CONTROL_AUDIT.mdと同じ。
全通常役・持越し・プレミアBまで含む完全ゲーム検査ではない。

## 検査した選択手順
1. 第一候補ごとに、どの第二入力にも安全な第二候補が0〜4コマ内に残ることを確認。
2. 通常条件で第一入力の窓に7があれば、0コマ候補を優先してBIG経路を残す。
3. それ以外は合法な1枚役入賞へ繋がる第一候補を優先。複数あれば滑りが少ない候補。
4. 第二候補は、全第三入力から0〜4コマで合法形に届くものに限定。
5. 第一が0コマで、第二も0コマの7がBIGラインへ繋がる場合は、その第二ビタ候補を優先。
6. それ以外は成立1枚役へ繋がる安全な第二候補を優先し、複数あれば滑りが少ない候補。
7. 第三は3リール全て0コマで正しい777が揃う入力を優先。次に0〜4コマで成立1枚役が揃う位置、最後に最小滑りの合法位置。
8. 未成立役は否定し、最終滑りで偶発777が揃う候補を除外する。
9. Fモデルは当選GのBIG入賞を許可せず、第二候補で5ラインのいずれかの既停止2リールが7二個になる形を除外する。

中第一停止の7上段/中段ビタ保護は確定仕様。
左/右第一の7保護、中下段7の保護、同順位の最小滑り選択は、既定のBIGビタ優先を具体化した研究案として検査したもので、別のユーザー発言による個別確定とは扱わない。
Fの7テンパイ判定は保守モデル。既存関数の正確な意味との照合は別途行う。
