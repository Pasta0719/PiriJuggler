# Phase 05 — 表示・音・告知
Status: COMPLETE — IMPLEMENTED_AND_RUNTIME_VERIFIED

## チャレンジ
レバー時にBAR/ベル/ピエロ各1/3で対象決定し、同じレバーでCHANCE下へ対応する既存PNGを表示。
第三停止後に消灯。成功ならボーナス告知音を1回だけ鳴らす。
指定外図柄を揃えても失敗、しかし蹴らず14枚払出。無役も14枚。
BAR揃いはチャレンジで許可し、777/77BARだけを否定する。
離席復帰・観覧で固定された対象や停止位置を別のものに変えない。

## 通常告知とプレミア
基本後告知。通常ランプからBIG/REGを公開しない。
A〜Fの既存音と点灯タイミングを継承し、制御は本機の確定優先順位を適用。
プレミア演出だから旧BAR強制揃い・自動回収等まで継承するわけではない。
Fは第二停止7テンパイを蹴り、当選G未入賞から告知・持越し。
通常ボーナス中にベル/ピエロを通常役の表示として出さず、チャレンジで使用する。

## 資産と確認
A/Bの画像は追加しない。内部だけ位置差で1枚役成否を変えない。
既存画像の縦横比を保ち、別機種のサイズ・色・音を変更しない。
操作画面と観覧画面で、対象点灯時刻、第三停止消灯、成功音1回、残りG、告知状態を照合。
画像表示後の操作再送で対象を再抽選したり成功音を重ねたりしない。
