# Phase 03 — 当選権利・残りG・再遊技・保存
Status: SPEC_ONLY — 実装未着手

状態表はSKILL_STOP_STATE_AND_PHASE_PLAN.md。BIG20G、REG8Gから開始し、残りGで終了を管理する。

## 1ゲームの確定処理
レバー時に抽選結果と対象図柄を一度だけ固定する。追加Gでも同じ抽選。
第三停止時に14枚払出、残りGを1減らし、チャレンジ成功なら3加算してから終了判定。
残り1から成功した場合は0で終了せず3G残る。
入賞図柄777/77BARは払出0で、入賞Gを初期残りGの消化に含めない。

## 持越しと再遊技
未入賞のBIG/REGは持越す。告知後は1BET専用小役抽選。
実際のリプレイ入賞の次Gだけ追加消費なし。無料Gでも同じ1BET抽選と通常停止法則。
新規小役で持越し権利を消さない。小役取りこぼしも当選取り消しにならない。
通常告知はBIG/REGを公開せず、プレミア認識によるBIG情報と分ける。

## 保存と再処理
離席・再接続・保存復帰で当選権利、残りG、無料再遊技、固定済み抽選結果、停止済み位置、チャレンジ対象を復元。
同じ第三停止の払出や3G加算を二重に行わない。再送でレバー抽選を引き直さない。
台単位の状態とプレイヤー所持枚数の更新を一貫させる。

## 受入例
残1成功→3、残1失敗→終了、追加G成功→さらに3、全失敗BIG20/REG8で終了。
リプレイ連続無料、未成立ボーナス拒否、成立1枚役取りこぼし後もBIG保持。
停止途中・告知待ち・ボーナス最終Gの離席復帰、第三停止再送、払出後再接続を検証。

## 通常ボーナス図柄の未決
現行NormalGame.drawBonusDisplayにはベル/ピエロ/ブドウ/チェリーがある。
ユーザー指定でベル/ピエロは通常ボーナスGから除外。チェリーを残す場合、取りこぼしなしと4コマ制限は両立しない入力がある。
左角チェリーの上段番号は4/6/14/16。全21入力中7入力で最短滑りが4を超え、最大8。
通常ボーナスだけ4超を許すか、チェリー表示も除いて別の通常表示にするかは未確定。
この未決は14枚払出額・残りG・チャレンジ確率を変更する理由にはしない。
