## 3. 第二停止のビタ許可・禁止
| 条件 | 指定済みの扱い |
| --- | --- |
| 成立役へテンパイするビタ位置 | 停止を許す。第三停止でビタ入賞を狙える |
| 成立役がテンパイしないビタ位置 | 取りこぼしとして許す。引き込まない |
| 非成立役のテンパイだけ | 第三停止までに入賞を否定する必要がある。テンパイ自体を全面禁止する指定はない |
| 左通常チェリーが中段 | 左停止時に蹴る。中リールは対象外 |
| 第一停止法則に矛盾する位置 | 矛盾を解消する滑りが必要 |
| プレミア停止 | 滑りなし指定。通常禁止ルールとの優先順位は未確定 |

第二停止で非成立役がテンパイしただけでは、入賞したことにしない。
既停止リールを第三停止時に動かさない。
第二停止の時点で第三停止の合法位置が残るかを検証する必要がある。
合法位置を残すための先行滑りの採否は未指定。必要性が判明しても勝手に仕様化しない。

## 4. 第三停止のビタ許可・禁止
| 最終候補の条件 | 指定済みの扱い |
| --- | --- |
| 成立小役が揃う | ビタ停止・指定払出 |
| 成立小役を取りこぼす | ビタ停止・その小役は払わない |
| 非成立小役が5ラインのどれかで揃う | 蹴る |
| 通常BAR/BAR/BARが5ラインのどれかで揃う | 蹴る |
| ボーナス未成立でBIG/REGが揃う | 蹴る |
| BIG成立中にREG組合せ、REG成立中にBIG組合せ | 蹴る |
| 当選Gまたは持越し中に正しいボーナスをビタで揃える | 入賞 |
| 禁止解消の滑りで成立小役が揃う | 許可・指定払出 |
| 禁止解消の滑りで正しいボーナスが揃う | ビタ限定条件を満たさないため、その位置も蹴る |

禁止を解消するための滑りが、別の禁止役を揃える場合も不可。
滑り先を決める最大コマ数と優先順位は未確定。
位置表はビタの候補であり、全組合せの最終滑り数が確定した完全制御表ではない。

## 2026-10-03 追加確定 — ピエロ重複の存続

- ピエロ重複BIG/REGを残す。
- ピエロを取りこぼしても、同時当選しているBIG/REGは無効にしない。
- ピエロ入賞の成否とボーナス当選・入賞は別に判定する。
- ピエロを取りこぼしたゲームでも、正しいボーナス図柄をビタで揃えた場合は当該ゲームで入賞を許可する。
- そのゲームでボーナスを揃えられなければ後告知・持越しとし、以後は1BETでビタ入賞できる。既存プレミア告知の例外は維持。
- ピエロが揃っていないのにピエロの10枚を払い出してはならない。
- 第一停止でピエロ専用滑りを優先するか、ボーナスの停止形を許すかは、この発言だけでは確定しない。
- 中上段7停止に含めるボーナスは単独だけ、という既存確定条件を維持する。
- 設定6の計算モデルには既にピエロ重複BIG/REGが含まれる。存続だけを理由に確率を二重追加しない。

## 2026-10-03 追加確定 — ピエロ重複滑り・左中段チェリー

### ピエロ重複
ピエロ重複BIG/REGにも単独ピエロと同じ第一停止制御を使用する。
- 中7上段狙い: 上段番号20→3、4コマ滑り、ピエロ上段
- 中7中段狙い: 上段番号21→3、3コマ滑り、ピエロ上段
- 右ブドウ/7/BAR狙い: 上段番号21→3、3コマ滑り、ピエロ上段
この中押し経路では中リールに7が出ないので当該ゲームでのボーナス入賞はできず、告知・持越し。
他の入力経路で正しいボーナスをビタで揃えられる場合の入賞許可は維持。

### 左中段チェリー
通常チェリーを左中段へ押した場合、1コマ滑らせて下段へ落とす。
- チェリー4が中段: 入力上段5→停止上段6
- チェリー14が中段: 入力上段15→停止上段16
チェリー成立またはチェリー重複成立時は下段チェリーとして停止し、成立形を満たせば4枚。
プレミアチェリーで中段ビタできた場合は既存指定どおり0コマで中段停止を許す。
チェリー非成立時には、下段へ落としただけでは非成立チェリー入賞の禁止と衝突するため、
既存の「矛盾しなくなるまで滑る」ルールに従って非成立入賞を回避する。
この指定を理由に非成立チェリーを払い出してはならない。

## ビタ限定入賞から導かれる禁止条件

通常時・入賞待ちとも、ボーナス図柄が滑った結果揃う位置は許可しない。
小役は禁止解消の滑りによる偶発入賞を許可するが、ボーナスには同じ例外を適用しない。
当選Gに正しいボーナスを揃えられなければ当選権利を持越す。

## 2026-10-03 確定 — 1BET小役払い出しとボーナス入賞

1BETでもブドウ8枚・チェリー4枚・ベル14枚・ピエロ10枚の払い出しを適用する。
小役が内部成立していても、正しい持越しボーナス図柄をビタで揃えたら、そのゲームでボーナスに入賞してよい。
小役成立を理由に正しくビタで揃えたボーナス入賞を強制的に蹴らない。
揃っていない小役の払い出しはしない。小役抽選で持越しボーナスを消滅させない。
リプレイが実際に揃った後の次ゲームBETは、この承認では未確定。

## 2026-10-03 確定 — 告知後も通常出目法則を維持

告知後1BET・その無料再遊技でも通常時の出目法則を維持する。
告知済みという理由だけで専用の自由ビタ停止へ切り替えない。
ブドウ成立中に中7上段をビタした場合は、通常法則に従い中ブドウ上段へ滑る。
その停止形で7が窓内にない場合は、そのゲームではボーナスを揃えられず持越し。
ピエロやベル等の専用滑りも告知後に維持する。
正しいボーナスを実際にビタで揃えられた経路での入賞許可は維持し、小役成立を理由に最終入賞を取り消さない。
新機種を作る指示ではなく仕様確定の継続。実装は開始しない。

## 次の制御確認 — 滑り上限
指定された中押し/逆押しの第一停止は0〜4コマに収まる。
非成立役を蹴る第二/第三停止については、通常の最大滑りを4コマで固定するか未確定。
「矛盾しなくなるまで滑る」と、4コマ以内で合法位置が存在しない場合の扱いを整合させる必要がある。
以前の距離訂正の会話だけを理由に最大滑りの承認を得たとは扱わない。
