# SKILL STOP PHASE 01 — 基本停止形の整合検査
Status: PARTIAL — SPEC ONLY
Updated: 2026-10-03

## 範囲
採用済み配列の上段位置21×21×21=9261通りを、12内部役について全列挙した。
研究用計算であり、ゲームコード・設定・実装テストは変更しない。
各役はMISS/REPLAY/GRAPE/BELL/PIERO/CHERRYと単独/チェリー重複/ピエロ重複BIG/REG。

## 使用した基本判定
- 5ラインの同図柄リプレイ/ブドウ/ベル/ピエロは、内部成立時のみ入賞形を許可
- チェリーまたはチェリー重複時のみ左上段/下段チェリーを許可
- 通常左中段チェリーは禁止
- 通常BAR3個揃いは禁止
- 777はBIG系のみ、77BARはREG系のみ許可
- 小役取りこぼしの停止形は許可

未確定のチェリー右条件・1枚役・図柄種類差は入れていない。
プレミア、持越し新規抽選、ボーナスのビタ限定入力履歴、最大滑り、指定第一停止経路はこの検査の対象外。
したがって最終の全制御検証完了を意味しない。

## 結論
- 左が最後なら、基本判定下では全既停止組に合法最終位置が存在する。
- 中/右が最後のdeadは、既に左で禁止チェリーを止めた組。
- 非チェリー内部役では左禁止位置6個×他リール21=126組。
- チェリー内部役では左中段チェリー禁止位置2個×21=42組。
- 左を止めた時点で禁止チェリーを蹴けば、基本判定に関するこのdead要因は解消する。
- 左チェリー禁止を第三停止だけへ先送りしてはならない。
- 全21位置での合法位置存在は、4コマ以内の合法位置存在とは別。4コマ制限付き全組検証は未完了。

## ピエロ取りこぼしとボーナス
ピエロ重複当選時、ピエロが揃っていなくても777/77BARは内部ボーナスに応じて許可する。
ボーナス入賞はユーザー指定のビタ限定。非入賞なら告知と持越し。
指定された中押し・逆押しでは単独ピエロと同じ第一停止滑りを適用する。

既存指定:
- 中上段7に含めるボーナスは単独だけ
- 逆押しベル/ピエロ成立時は専用滑り優先

採用済み第一停止法則（2026-10-03）:
- ピエロ重複もピエロ専用滑りを使う
- 中上段7狙い→中上段ピエロ3へ4コマ
- 中中段7狙い→中上段ピエロ3へ3コマ
- 右ブドウ7BAR狙い→右上段ピエロ3へ3コマ

この案では、中上段ピエロ停止時は7が中リール窓内にないため、その入力経路のゲームではBIG/REG図柄を揃えられない。
「ピエロ取りこぼし時でもボーナス当選を維持する」と矛盾しないが、
他の入力経路ではビタ入賞を許可し、この経路では後告知・持越しとなる。
2026-10-03にユーザーがこの案を了承。ピエロ重複にも単独ピエロと同じ第一停止滑りを適用する。

## 2026-10-03 追加確定 — ピエロ重複滑り・左中段チェリー

### ピエロ重複
ピエロ重複BIG/REGにも単独ピエロと同じ第一停止制御を使用する。
- 中7上段狙い: 上段番号20→3、4コマ滑り、ピエロ上段
- 中7中段狙い: 上段番号21→3、3コマ滑り、ピエロ上段
- 右ブドウ/7/BAR狙い: 上段番号21→3、3コマ滑り、ピエロ上段
この中押し経路では中リールに7が出ないので当該ゲームでのボーナス入賞はできず、告知・持越し。
他の入力経路で正しいボーナスをビタで揃えられる場合の入賞許可は維持。

### 左中段チェリー
通常チェリーを左中段へ押した場合、1コマ滑らせて下段へ落とす。
- チェリー4が中段: 入力上段5→停止上段6
- チェリー14が中段: 入力上段15→停止上段16
チェリー成立またはチェリー重複成立時は下段チェリーとして停止し、成立形を満たせば4枚。
プレミアチェリーで中段ビタできた場合は既存指定どおり0コマで中段停止を許す。
チェリー非成立時には、下段へ落としただけでは非成立チェリー入賞の禁止と衝突するため、
既存の「矛盾しなくなるまで滑る」ルールに従って非成立入賞を回避する。
この指定を理由に非成立チェリーを払い出してはならない。
