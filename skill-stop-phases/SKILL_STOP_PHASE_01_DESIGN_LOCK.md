# SKILL STOP PHASE 01 — 目押し攻略機の仕様整理

Status: **IN_PROGRESS — SPEC ONLY**
Updated: 2026-10-03
機種名: 未決定（SKILL STOPは文書管理用の仮称）

## Goal / Scope

ユーザーとの相談で仕様を詰め、確定事項と未決事項を分けて記録する。
**実装は開始しない。** コード・画像・音源・設定値・実行ワークフローは変更しない。
既存GOD/EXTREME/NEXT機種の仕様・Phase進行も変更しない。
仕様確定後も、実装開始には別途ユーザーの指示が必要。

## 1. リール・有効ライン・払い出し

- ミスタージャグラーの実機配列をそのまま使用する。配列改造はしない。
- 正確な配列・図柄差・番号・回転方向は資料確認のうえ転記する。現時点では未確認。
- 有効ラインは5ライン。
- 各役の成立形は「通常と同じ」。具体的な図柄差、チェリー判定、ボーナス組合せ等の転記は参照対象を確認してから行う。

| 小役 | 払い出し |
| --- | ---: |
| ブドウ | 8枚 |
| ベル | 14枚 |
| ピエロ | 10枚 |
| チェリー | 4枚 |

リプレイの扱い、通常投入枚数は今回の指定では未確定。

## 2. 通常時の取りこぼし・基本停止制御

- 全小役が取りこぼし対象。役に対する積極的な引き込みは行わない。
- 基本は滑りなし。
- 出目法則に矛盾する場合、または内部非成立役が揃う場合は、矛盾が解消するまで滑らせる。
- 矛盾解消の結果、内部成立役を引き込むことは許容する。
- 下記の中押し・逆押し固有制御にあるブドウ等への滑りは、ユーザー指定の例外として適用する。
- 通常時のBAR揃いは否定する。
- ボーナス成立ゲーム以外で、ボーナス図柄が5ラインのいずれかに揃うことを否定する。
- 通常チェリーは中段に止まらない。
- プレミアチェリーに限り、中段に押せたら止まる。
- 最大滑り数、禁止制御同士の優先順位、プレミアチェリーの抽選・恩恵は未決定。

## 3. 中押し：中リール7上段狙い

「押した位置」と「滑った後の停止位置」を区別する。

| 入力・停止経路 | 対応する内部成立 |
| --- | --- |
| 上段ビタ入力から上段停止 | ベル or BIG or REG |
| 上段ビタ入力から中段へ滑る | チェリー or チェリー重複ボーナス |
| 中段ビタ入力から中段停止 | チェリー or チェリー重複ボーナス or ベル or 単独ボーナス |

- 上段7停止後は、左右をビタで揃えてもらう。
- 成立しているボーナス図柄を正しく押せた場合、そのままボーナスに入る。
- 上段・中段の対応役がいずれも成立していないときに上段/中段へ押した場合、7は下段へ滑る。
- ブドウ成立時はさらに滑り、最も近いブドウを中リール上段に止める。
- ピエロ成立時もさらに滑り、最も近いピエロを中リール上段に止める。
- チェリー重複時の上段停止と中段滑りの選択、その他の入力位置・押し順の制御は未決定。

## 4. 逆押し始動

対象の右リール停止形（ユーザー表記）: **ブドウ・7・BAR**
上下の対応と配列番号は資料確認後に明示する。

- 対象形が止まった場合、ブドウ or ボーナス（チェリー重複を含む）。
- ピエロ成立時は滑り、最も近いピエロを右リール上段に止める。
- ベル成立時も同様に、最も近いベルを右リール上段に止める。
- ブドウもボーナスも成立していない場合、7が下段へ滑って止まる。
- 最後の条件とベル/ピエロ専用制御の優先関係は確認事項。勝手に統合しない。

## 5. ボーナス告知・入賞

- 告知方式は今まで通り。ただし基本すべて後告知。
- ボーナス図柄はビタで押すまで揃わない。
- 告知後はすべて1BET。
- 成立していないボーナス組合せをビタ押しした場合（例: REG成立中に777）、そのゲームの上記滑り制御に沿って蹴る。
- 当選ゲームでは、正しいボーナス図柄をビタで揃えた場合、そのまま入賞できる。
- 持越し後の入賞許可は「成立ゲーム以外で揃い否定」との整合を確認する。
- 基本すべて後告知の例外、当選ゲームで即入賞した場合の告知、告知後1BET時の役抽選・払い出しは未決定。

## 6. ボーナス通常ゲーム・チャレンジ制御

- 基本は従来の取りこぼしなしのボーナスシステム。
- 現行機種にあったベル・ピエロはボーナス中の通常役として出さない。チャレンジ対象として使用する。
- チャレンジはBIG・REGどちらでも発生する。
- 内容は「指定図柄を5ラインのいずれかで揃えなさい」。
- 対象はBAR揃い、ピエロ揃い、ベル揃いのいずれか。
- チャレンジ中は、ボーナス図柄の一直線揃いを蹴る以外、滑らせない。
- 指定対象と違う役が揃った場合も、無役の場合も14枚払い出す。
- 通常時のBAR揃い否定・非成立小役否定を、そのままチャレンジへ持ち込まない。
- BARはチャレンジ対象として揃えられる必要がある。BAR対象許可と「ボーナス図柄一直線」の禁止範囲は明示確認する。
- チャレンジ対象の選択比率、チェリー中段禁止の適用範囲は未決定。

## 7. チャレンジの払い出し・報酬

- 成功・失敗にかかわらず、該当ゲームは14枚払い出し。
- 成功報酬は追加ボーナスゲーム3G。
- 追加3G内での再チャレンジ抽選、追加ゲームの払い出し、既存ボーナス終了条件と追加Gの関係は未決定。
- 成功率・追加G内の抽選を含む期待値を確認してから発生率を調整する。

## 8. 発生頻度・画像・音

- 発生率の目安は1/5。期待値次第で変更してよい。
- BAR/ベル/ピエロから対象を抽選・決定する。
- 決定された図柄のPNGを、レバーオンと同時にCHANCEランプ下へ点灯表示する。
- 第三停止後に消灯する。
- 成功した第三停止後、ボーナス告知音を1回鳴らす。
- このPhaseではPNGや音源を作らない。

## 確認事項・残作業

### 制御の整合に必要な確認

1. ボーナスの持越し後もビタで入賞できるか。「成立ゲーム以外で揃い否定」の成立ゲームに持越し中のゲームを含むか。
2. 上段7ビタ入力でチェリー重複ボーナス成立時、上段停止を許すか、中段へ必ず滑らせるか。
3. 逆押しのベル/ピエロ成立時は上段への専用滑りを優先し、7下段停止はそれ以外の非ブドウ・非ボーナスに限るか。
4. チャレンジ中の「ボーナス図柄一直線を蹴る」はBAR揃いを除くか。BAR以外を指定した場合のBAR揃いも許可するか。
5. 成功で追加された3Gでも再チャレンジを抽選するか。

### その他の未決・未確認

- 機種名
- 正確な実機配列・出典・番号・図柄差
- 「通常と同じ」の参照対象と正確な役構成、ボーナス組合せ
- リプレイ、通常投入枚数、複数ライン入賞時の扱い
- プレミアチェリーの抽選・払い出し・ボーナス関係
- 未指定の押し順・入力位置の制御
- 最大滑り数・方向・制御優先順位・合法停止位置がない場合の扱い
- ビタ判定の入力時点・コマ境界
- ボーナス基本終了条件、追加Gとの整合、ボーナス通常ゲームの払い出し
- 1BETでの小役抽選・払出し・入賞制御
- 後告知の例外と当選ゲーム即入賞時の告知
- 対象選択比率、発生率の最終値
- ボーナス確率・小役確率・設定差・機械割
- 後続Phase構成・受入条件

## Exit gate / Stop condition

配列の確認、役契約、全押し順の停止制御、ボーナス入賞、チャレンジと追加G、表示と音の仕様を矛盾なく定義する。
実装に必要な未決事項が解消し、ユーザーが仕様確定を了承するまではIN_PROGRESSとする。
仕様確定後も実装へ自動移行しない。
