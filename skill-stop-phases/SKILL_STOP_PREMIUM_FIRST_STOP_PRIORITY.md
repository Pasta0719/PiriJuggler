# プレミアA〜Eと通常第一停止法則の優先関係
Status: NEEDS_DECISION — SPEC ONLY
Updated: 2026-10-03

## 確定済み
通常チェリー重複BIGで中7上段ビタ（上段入力20）は1コマ滑って中7中段（上段21）。
通常ピエロ重複BIGでは同入力を4コマ滑って中ピエロ上段（上段3）。
プレミアA〜Eは基本滑りなし、禁止出目回避と第二先読みは例外。追加1枚役引き込みも例外として了承済み。
Fの第二停止7テンパイ否定と当選G直接入賞禁止は維持する。

## 必要な優先順位
追加1枚役のプレミア引き込みを承認しただけでは、既存チェリー/ピエロ重複プレミアの第一停止法則まで優先順位が決まらない。
次の2条件は、中7上段入力20で同時には満たせない。
- 通常第一停止法則を維持: チェリーBIGは20→21、ピエロBIGは20→3。
- プレミアA〜Eで指定第一停止滑りも行わない: 中7を上段20へビタ停止し、左右の上段7ビタで当該G入賞を狙える。

通常指定法則による滑りは、未成立役・禁止出目回避や1枚役引き込みとは別の理由なので、既存の例外許可だけから自動確定しない。
プレミアBの左中段チェリービタ許可はそのまま維持する。
新機種でA〜Eのチェリー/ピエロ重複時は通常第一停止法則を優先するか、プレミア基本ビタ停止を優先するかを確認する。
ゲーム実装は変更しない。
