# Phase 02 — 配列・入力・停止制御の実装契約
Status: SPEC_ONLY — 実装未着手

採用配列はSKILL_STOP_REEL_STOP_CONTRACT.md。入力番号と既存回転の対応はSKILL_STOP_INPUT_TIMING_CONTRACT.md。
通常役・持越し・追加1枚役・プレミア・ボーナス通常G・チャレンジを別の制御条件として扱い、同じ禁止判定を無条件に流用しない。

## 制御順
1. 内部役、持越しボーナス、プレミア、入力履歴から当該モードの候補を作る
2. 既停止リールは固定し、指定第一停止法則を適用
3. 第二はどの第三入力でも4コマ以内の合法位置を残す候補に限定
4. 正しいボーナスのビタ入賞経路を、追加1枚役引き込みのために消さない
5. 追加1枚役だけ最大4コマで回収。通常小役を積極的に引き込まない
6. 同順位は最小滑りを候補案の基準にする。禁止・指定法則を破って最小滑りにしない
7. 第三停止で全5ラインを再照合して払出と入賞を確定

A〜EでもチェリーBIGは中20→21、ピエロBIGは中20→3。Fの第二7テンパイ否定は優先し、当選Gの直接入賞なし。
追加6種類はMR_JUGGLER_ONE_MEDAL_REFERENCE.mdの表だけ。ONE_Gを役や禁止図柄として残さない。
ボーナス図柄を最後の引き込みで揃えない。指定第一停止法則で滑った7を、その後のビタで揃える許可経路は残す。

## 受入証拠
全内部役×6押し順×入力履歴を対象に、指定停止、滑り数、役成立ライン、払出、ボーナス入賞、持越しを記録。
未成立役/通常BAR/違うボーナスの入賞0件、範囲外滑り0件、第三入力による行き詰まり0件を確認。
既に実施した基本形列挙・1枚役666,792履歴の研究を、実装検証の代わりにしない。
通常ボーナスのチェリーと最大滑りの両立はPhase03の未決を先に解消する。
