## 確定した状態遷移
| 状態 | きっかけ | 遷移・処理 |
| --- | --- | --- |
| 通常 | BIG/REG内部当選 | 正しい図柄をビタで揃えたら入賞。それ以外は指定後告知と持越し |
| 告知後入賞待ち | BET | 1枚投入 |
| 告知後入賞待ち | レバー | 1BET専用小役抽選。持越し権利を保持。通常出目法則を維持 |
| 入賞待ち | リプレイ入賞 | 次G無料、1BETと同じ抽選/払い出し/制御 |
| 入賞待ち | ボーナスビタ入賞 | 図柄払出0、BIG残20GまたはREG残8Gで開始 |
| ボーナス待機 | BET | 2枚投入 |
| ボーナス待機 | レバー | BIG1/15・REG1/9でチャレンジ抽選 |
| チャレンジ | レバー | BAR/ベル/ピエロ各1/3、図柄PNG点灯 |
| ボーナスゲーム | 第三停止 | 14枚払出、残り-1G |
| チャレンジ成功 | 第三停止 | 残り+3G、告知音1回、PNG消灯 |
| チャレンジ失敗 | 第三停止 | 追加なし、PNG消灯 |
| ボーナスゲーム終了判定 | 減算・成功加算後 | 残り0Gなら終了、残りありなら継続 |

残りG、当選権利、回転中の抽選結果を離席で消滅させない。
報酬追加と払出しの同じ第三停止処理を再処理して二重加算しない。
これは状態の一貫性要件であり、実装変更ではない。

## 1BET持越し時の第一停止優先順位 — 未決の詳細
通常法則を維持し小役を新規抽選する条件では、持越しボーナスと当該Gの小役が並存する。
中7上段狙いで新規ブドウが成立した場合のブドウ滑りはユーザー確定。
新規ベル/ピエロの専用滑りも維持する。
未入賞の持越し権利そのものを当該Gの単独/重複当選と同一視する処理は、明示確認前に確定しない。
特にリプレイ成立時は、単独ボーナスの上段停止とリプレイの下段停止で候補が異なる。
入賞待ちゲームの攻略手順・期待BETの最終計算前に確認する。
